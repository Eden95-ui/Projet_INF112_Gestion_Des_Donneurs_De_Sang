# Projet_INF112_Gestion_Des_Donneurs_De_Sang
Dans le cadre de notre évaluation pratique il nous a été demander de réaliser un projet mettant en pratique l’utilisation des listes chaînées et la gestion dynamique de la mémoire en langage C. Nous avons décides de mettre sur pied un Système de Gestion des donneurs de sang dans les hôpitaux du Cameroun.
